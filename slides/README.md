# Presentation

`Project4_Team4_Presentation.pdf` contains the twelve slides. `Project4_Team4_Presentation.pptx` is the editable version, with speaker notes and suggested timing for the 12-minute talk.

The recorded prediction example uses four New York forecasts. The issue date shows when a forecast could have been made; the target date is twelve months later. Actual temperatures are included to score the historical predictions. The numbers are saved in `outputs/phase1/recorded_prediction_demo.csv`.

`presentation_data.json` contains the tables used to prepare the slides. Both speakers should review every result and adjust the speaking split to their actual roles.
