# Notebooks

[Project4_Team4.ipynb](Project4_Team4.ipynb) is the prepared final notebook. It has all nine required sections, saved outputs, and ten regressors evaluated at both forecast lead times.

[Open it in Colab](https://colab.research.google.com/drive/1RuUMDKWYnloyxGTN7VvgyQ9vIT4PtUXs), then choose **Runtime → Run all** to check it on Google's runtime using the updated shared copy. See [sync status](../docs/PUBLISHING_STATUS.md).

`archive/` keeps earlier checkpoints. Their results may differ from the final analysis, so use the main notebook for the report and presentation. `scripts/build_notebook.py` creates the earlier starter notebook; it does not rebuild the final version.
